================================================================================
SELF-MANAGED KUBERNETES
SIMPLE USAGE GUIDE
================================================================================

This folder contains:

    controller.sh  -> Run on the Controller node
    worker.sh      -> Run on the Worker node

Kubernetes : v1.34
OS         : Ubuntu 22.04
Runtime    : containerd
CNI        : Flannel

Cluster:

    Controller
        |
        +---- Worker1


================================================================================
SECTION 1 - CONTROLLER
================================================================================

STEP 1 - SSH INTO CONTROLLER

    ssh -i ~/.ssh/id_ed25519 azureuser@<CONTROLLER_PUBLIC_IP>


STEP 2 - GO TO THE SCRIPT

    cd ~/self-managed-k8s-automation/Azure


STEP 3 - MAKE SCRIPT EXECUTABLE

    chmod +x controller.sh


STEP 4 - RUN CONTROLLER SCRIPT

    sudo ./controller.sh


The script automatically:

    - Disables swap
    - Installs containerd
    - Installs kubeadm
    - Installs kubelet
    - Installs kubectl
    - Configures Kubernetes networking
    - Initializes the Kubernetes control plane
    - Installs Flannel
    - Configures kubectl
    - Generates a worker join command


STEP 5 - GET WORKER JOIN INFORMATION

Run:

    sudo kubeadm token create --ttl 0 --print-join-command


You will get something similar to:

    kubeadm join 10.20.1.4:6443 \
      --token abcdef.0123456789abcdef \
      --discovery-token-ca-cert-hash sha256:123456...


You need these 3 values:

    1. Controller IP

       10.20.1.4

    2. Token

       abcdef.0123456789abcdef

    3. CA certificate hash

       sha256:123456...


Keep these values safe.

DO NOT commit the token to GitHub.


================================================================================
SECTION 2 - WORKER
================================================================================

STEP 1 - SSH INTO WORKER

    ssh -i ~/.ssh/id_ed25519 azureuser@<WORKER_PUBLIC_IP>


STEP 2 - GO TO THE SCRIPT

    cd ~/self-managed-k8s-automation/Azure


STEP 3 - MAKE SCRIPT EXECUTABLE

    chmod +x worker.sh


STEP 4 - RUN WORKER SCRIPT

Use the 3 values generated on the Controller:

    sudo ./worker.sh \
      <CONTROLLER_PRIVATE_IP> \
      <TOKEN> \
      <CA_CERT_HASH>


Example:

    sudo ./worker.sh \
      10.20.1.4 \
      "abcdef.0123456789abcdef" \
      "sha256:123456..."


The script automatically:

    - Checks that all 3 parameters are provided
    - Disables swap
    - Installs containerd
    - Installs kubeadm
    - Installs kubelet
    - Configures Kubernetes networking
    - Waits for the Controller API
    - Runs kubeadm join
    - Joins the Worker to the cluster


If any parameter is missing, the script stops immediately.


================================================================================
VERIFY THE CLUSTER
================================================================================

Go back to the Controller:

    kubectl get nodes -o wide


Expected:

    NAME         STATUS   ROLES
    controller   Ready    control-plane
    worker1      Ready    <none>


Check all pods:

    kubectl get pods -A


================================================================================
TROUBLESHOOTING
================================================================================

Check Controller logs:

    sudo tail -f /var/log/kubeadm-controller-bootstrap.log


Check Worker logs:

    sudo tail -f /var/log/kubeadm-worker-bootstrap.log


Check nodes:

    kubectl get nodes


If Worker cannot connect to Controller:

    Check that port 6443 is allowed between Worker and Controller.

If the Worker was previously joined:

    sudo kubeadm reset -f

Then run worker.sh again.


================================================================================
IMPORTANT
================================================================================

Never put the kubeadm token inside GitHub.

Generate a fresh join command on the Controller when needed:

    sudo kubeadm token create --ttl 0 --print-join-command


The Controller private IP must be reachable from the Worker.
